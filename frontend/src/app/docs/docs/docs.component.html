Bitcoin Cash explorer documentation

Blocks, transactions and addresses

Search a block height, block hash, transaction ID, Bitcoin Cash address, or supported explorer URL. A 64-character hash may belong to several chains; manual chain selection stays available.

Bitcoin Cash targets one block every 10 minutes. ASERT adjusts mining difficulty after each block. The block subsidy halves every 210,000 blocks.

1 BCH = 100,000,000 satoshis. Fee rates use sat/B. Fiat values use the current exchange rate.

Addresses and CashTokens

Search CashAddr or legacy Bitcoin Cash addresses. CashTokens are separate from BCH amounts.
