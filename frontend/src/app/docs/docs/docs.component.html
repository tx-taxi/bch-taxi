Bitcoin Cash explorer documentation

Blocks, transactions and addresses

Search a block height, block hash, transaction ID, Bitcoin Cash address, or supported explorer URL. A 64-character hash may belong to several chains; manual chain selection stays available.

Bitcoin Cash targets one block every 10 minutes. ASERT adjusts mining difficulty after each block. The block subsidy halves every 210,000 blocks.

1 BCH = 100,000,000 satoshis. Fee rates use sat/B. Fiat values use the provider's Bitcoin Cash prices and may lag the market.

Privacy and coverage

Address history supports CashAddr and legacy Bitcoin Cash addresses. BCH amounts do not describe CashToken balances: token metadata and input quantities may be unavailable, and each affected view identifies that limitation.

The pending view shows a bounded provider sample, not a complete global mempool. Different nodes may see different transactions. Estimates are not confirmation guarantees.

Read-only API

Requests use the same local origin. Successful retained responses carry X-BCH-Observed-At and X-BCH-Stale headers. Provider failures return 503; absence returns 404. This local review does not broadcast transactions.
