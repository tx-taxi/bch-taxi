Bitcoin Cash documentation

Amounts and fees

1 BCH = 100,000,000 satoshis. Fee rates are satoshis per serialized byte. Bitcoin Cash does not use SegWit, MWEB, Taproot or Bitcoin’s replacement-by-fee policy.

Blocks and mining

Bitcoin Cash targets a block every 600 seconds and adjusts difficulty with ASERT after each block. Subsidy halves every 210,000 blocks. The block size limit is adaptive.

Addresses and tokens

CashAddr addresses may include the bitcoincash: prefix. Legacy 1/3 addresses are shared with other Bitcoin forks and require explicit chain context. CashToken amounts are token base units, separate from the BCH carried by their output. Unverified token names and decimal scales are not guessed.
