# BCH localization review

Production was observed serving Spanish at `6c29ad5c0`; the completion worktree is based on that release. French and German are prepared with Spanish, using the existing Angular/Mempool catalogs and localized builds. The BCH-specific entries in the Spanish catalog have corresponding French and German translations, including documented CashTokens, privacy, provider status, API, and FAQ content. Generic translations were reused from the Bitcoin explorer only for unique exact source matches that do not refer to Bitcoin, BTC, Liquid, or mempool.space. This does not establish full coverage of the active application; run a fresh extraction and review unmatched and stale units as well as unmarked UI before treating any locale as complete.

The localized server responses have locale-specific `lang`, self-canonical paths, and `noindex, follow` both as meta and response header. English retains existing metadata and indexing. No new hreflang or sitemap entry is exposed. The Angular SEO service now retains `es`, `fr`, and `de` canonical prefixes after hydration and navigation. Documentation anchor links retain their localized path and query string, including modified-click behavior.

A local production Angular build for Spanish, French, and German succeeded before the final generic/footer catalog additions and the subsequent SEO and documentation link fixes. Manual preview checked French about and FAQ, German privacy, the language selector and legal data; the build reported additional missing-translation warnings. A final build, fresh extracted-catalog audit, and browser verification of post-hydration canonicals and documentation deep links are required before deployment. No indexing should be enabled solely on these checks.
